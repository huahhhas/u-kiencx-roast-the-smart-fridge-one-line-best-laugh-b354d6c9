# Roast the Smart Fridge: One Line, Best Laugh Wins

A make.fun bounty entry. `main.py` (Python 3.13, standard library only,
deterministic, no network) writes a single roast line — at most 160
characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> My smart fridge has Wi-Fi, a camera, a touchscreen, yet it can't tell me what's inside — a $3,000 snitch reporting my 2 a.m. snacking to an app I never open.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fridge-out python3 main.py
cat /tmp/fridge-out/entry.txt
```
